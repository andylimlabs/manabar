What you see

Depletion

When an agent is burning tokens you can watch it happen. The bar drops, and a pale ghost hangs where it used to be for a couple of minutes, so a heavy run is hard to miss.

Restoration

When the window resets, the bar fills back up with a gold flash and a toast shows how much you got back. Before that, the readout shows the reset time so you know what you're waiting on.

Status

The readout shows each meter's percentage and reset time, and every display gets its own bar.

Gamer mode

Want a little fun? Turn on Gamer mode and the labels read like you're in an MMO.
